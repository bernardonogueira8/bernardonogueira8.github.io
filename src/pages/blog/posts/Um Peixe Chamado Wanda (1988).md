# Resumo
Com o intuito de seduzir Archie para descobrir o esconderijo das jóias roubadas por um de seus clientes, Wanda está pronta para agir! Infelizmente para ambos, o namorado e parceiro da moça (Kline) também está pronto para agir, mas contra Archie! Quem ficará com as jóias? Quem ficará com Wanda? Fica aqui o suspense, mas uma coisa é certa: "Um Peixe Chamado Wanda" é um filme que com certeza vai fisgar você!
